# سكربت فحص شبكي متقدم (Network Scanner)

مشروع نموذجي لقسم **أدوات شبكات** — فاحص منافذ متزامن بلغة Python.

## الملفات
| الملف | الوظيفة |
|---|---|
| `network_scanner.py` | الفاحص الرئيسي (اكتشاف الأجهزة والمنافذ المفتوحة) |
| `requirements.txt` | الاعتماديات (لا شيء — مكتبات قياسية) |

## التشغيل
المتطلبات: Python 3.8+

```
python network_scanner.py 192.168.1.1 -p 1-1024
python network_scanner.py scanme.example.com -p 22,80,443 -w 50
```

> المرور عبر `-p` يدعم نطاقاً واحداً مثل `1-1024` (وليس قائمة مفصولة بفواصل) في هذه النسخة المبدئية.

## الوظائف
- فحص متزامن بالعديد من المحادثات (Threads) لسرعة أعلى.
- مهلة اتصال 0.6 ثانية لكل منفذ.
- طباعة المنافذ المفتوحة وعددها الإجمالي.

## ملاحظة أمان
شغّل الفاحص على شبكاتك أو بترخيص صريح فقط من صاحب الشبكة.

> هذا المشروع هو نسخة مبسطة (Starter) من المشروع المعروض في قسم أعمالي بالموقع.
