# أداة فحص ثغرات الويب

مشروع نموذجي لقسم **أدوات أمن سيبراني** — فاحص أولي لتقييم أمان تطبيقات الويب بلغة Python.

## الملفات
| الملف | الوظيفة |
|---|---|
| `web_security_scan.py` | الفاحص الرئيسي |
| `requirements.txt` | الاعتماديات (لا شيء — مكتبات قياسية) |

## التشغيل
المتطلبات: Python 3.8+

```
python web_security_scan.py https://example.com
```

## ما يفحصه
1. **ترويسات الأمان** المطلوبة: HSTS، CSP، X-Content-Type-Options، X-Frame-Options.
2. **علامات الهجوم** في جسم الاستجابة: أنماط SQL Injection و XSS.

## ملاحظة أمان
استخدم الأداة على أنظمتك أو بترخيص كتابي فقط من صاحب النظام، وإلا فإن استخدامها يعدّ مخالفاً للقوانين.

> هذا المشروع هو نسخة مبسطة (Starter) من المشروع المعروض في قسم أعمالي بالموقع.
