# تطبيق مراسلة مشفّرة من طرف إلى طرف

مشروع نموذجي لقسم **تطبيقات جوال** — هيكل تطبيق Flutter لمراسلة فورية مع تشفير الرسائل.

## الملفات
| الملف | الوظيفة |
|---|---|
| `pubspec.yaml` | إعدادات مشروع Flutter والاعتماديات |
| `lib/main.dart` | واجهة المحادثة مع تشفير/فك تشفير الرسائل |

## التشغيل
اشترط تثبيت [Flutter SDK](https://flutter.dev):

```
flutter pub get
flutter run
```

أو لبناء نسخة أندرويد:

```
flutter build apk --release
```

## ملاحظة
مثال التشفير داخل `lib/main.dart` يوضّح فكرة التشفير المتدفق (Stream Cipher) بمفتاح مشترك. في النسخة الإنتاجية يُستبدل بنظام مفاتيح عامة/خاصة (E2E) مثل Signal Protocol، وحفظ المحادثات على الخادم بشكل مشفّر فقط.

> هذا المشروع هو نسخة مبسطة (Starter) من المشروع المعروض في قسم أعمالي بالموقع.
