# منصة تعليم إلكتروني ذكية

مشروع نموذجي لقسم **مواقع ويب** — واجهة تعرض الدورات التدريبية مع اختبار تفاعلي بسيط.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية للمنصة |
| `style.css` | التنسيقات الكاملة |
| `script.js` | عرض الدورات وتشغيل الاختبار التفاعلي |

## التشغيل
افتح `index.html` في أي متصفح مباشرةً، أو شغّلها عبر خادم محلي:

```
php -S localhost:8000
```

ثم افتح `http://localhost:8000`.

## الفكرة
- نظام تسجيل الطلاب واختبارات تفاعلية.
- لوحة تحكم للمعلمين مع تقارير تقدّم لحظية.
- مبنية بأمان عالٍ وحماية كاملة للبيانات.

> هذا المشروع هو نسخة مبسطة (Starter) من المشروع المعروض في قسم أعمالي بالموقع.
